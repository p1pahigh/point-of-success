# Как продолжить работу над сайтом в новом Claude

В этой папке всё, что нужно: сайт, кабинет, логотип, ТЗ и брендбук (`docs/`, только на компьютере: репозиторий публичный, в GitHub эту папку не отправляем), служебные программы для проверок (`tools/`) и файл `CLAUDE.md`. В `CLAUDE.md` описано, как всё устроено, что уже сделано, какие решения вы принимали и какие вопросы остались открытыми. Новый Claude читает его сам при каждом запуске.

## Вариант 1. В редакторе VS Code (как сейчас)

1. Откройте VS Code.
2. В меню **File → Open Folder…** (Файл → Открыть папку) выберите эту папку целиком. Не отдельный файл, а именно папку.
3. Откройте панель Claude Code (значок Claude справа вверху или в боковой панели) и начните новый разговор.
4. Первым сообщением напишите, например:

   > Прочитай CLAUDE.md, это продолжение работы над сайтом The Point of Success. Забери свежие правки с GitHub, открой сайт в Safari и скажи, что понял по проекту и какие вопросы ко мне остались.

## Вариант 2. В Терминале

1. Откройте программу «Терминал».
2. Введите две команды, нажимая Enter после каждой:

   ```
   cd ~/Downloads/point-of-success-handoff
   claude
   ```

3. Напишите то же первое сообщение, что в варианте 1.

## Работа вдвоём с другом и на другом компьютере

С 15 ноября 2026 общая копия сайта лежит в закрытом хранилище на GitHub: https://github.com/p1pahigh/point-of-success

- После каждой правки Claude сам отправляет её туда. Чтобы получить правки друга, скажите Claude «забери правки».
- Другу перешлите файл `FRIEND_SETUP.md` (только его, не всю папку). Его Claude по этому файлу всё установит и скачает проект. Когда друг пришлёт логин на GitHub, пригласите его: https://github.com/p1pahigh/point-of-success/settings/access → **Add people**.
- На другом своём компьютере сделайте то же, что друг: откройте в Claude Code файл `FRIEND_SETUP.md` и попросите «сделай всё по этой инструкции».
- Сайт откроется на любом компьютере двойным щелчком по `index.html`. Но снимки страниц и автоматические проверки, которыми Claude проверяет свою работу, работают только на Mac.

## Что важно знать

- Тестовые аккаунты, которые вы создавали на странице записи, хранятся только в вашем браузере и в новую папку не переносятся. Демо-входы работают всегда: `student@demo.ru` и `teacher@demo.ru`, пароль `demo123`.
- Сайт пока прототип: нет сервера, настоящей оплаты и отправки данных. Подробно об этом в `CLAUDE.md`, раздел «Что пока ненастоящее».
- В разделе «О нас» ещё ждут ваших данных: фраза под заголовком, имя, фото и текст основательницы. Их можно просто прислать новому Claude.
- Снимок экрана можно вставить прямо в окно Claude: Cmd + Ctrl + Shift + 4, выделить область, затем Ctrl + V в Терминале или Cmd + V в VS Code.
- Приватное превью https://claude.ai/artifact/L2m2RMAxQYHiExugu6baeg открывается только в вашем аккаунте Claude. Новый Claude может обновить его, если попросить.
- Проект лежит в папке «Загрузки» → `point-of-success-handoff`. Других копий на компьютере нет, старые удалены 13 ноября 2026. Общая копия — на GitHub.
